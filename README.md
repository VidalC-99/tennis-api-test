# Tennis API

REST API for managing tennis players and player statistics.

Players come from a static dataset (`data/headtohead.json`) loaded in memory at
startup. There is no database: a player created through the API is visible to the
following requests, but is lost when the process restarts.

## Requirements

- Node.js
- npm

## Installation

```bash
npm install
```

## Running the API

```bash
npm run dev     # development server with hot reload
npm run build   # compile TypeScript to dist/
npm start       # run the compiled server
npm test        # run the tests
```

The API listens on `http://localhost:3000` (override with the `PORT`
environment variable). Interactive documentation is available at
**http://localhost:3000/docs**.

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/health` | Returns `{ "status": "ok" }` when the service is up |
| `GET` | `/players` | Players sorted by rank, best first |
| `GET` | `/players/stats` | Aggregated statistics over every player |
| `GET` | `/players/:id` | A single player |
| `POST` | `/players` | Create a player |

### Listing players

```bash
curl http://localhost:3000/players
curl "http://localhost:3000/players?country=SUI"
```

The optional `country` parameter filters on the three-letter country code. A
code matching nobody returns an empty array.

### Creating a player

The identifier is generated by the API, so it must not be sent. Every other
property is required, and any unknown property is rejected.

```bash
curl -X POST http://localhost:3000/players \
  -H 'Content-Type: application/json' \
  -d '{
    "firstname": "Roger",
    "lastname": "Federer",
    "shortname": "R.FED",
    "sex": "M",
    "country": { "picture": "https://example.com/suisse.png", "code": "SUI" },
    "picture": "https://example.com/federer.png",
    "data": {
      "rank": 3, "points": 2500, "weight": 85000,
      "height": 185, "age": 37, "last": [1, 1, 1, 1, 0]
    }
  }'
```

Note the units used by the dataset: `weight` is in **grams**, `height` in
**centimeters**. `last` holds the recent results, `1` for a win and `0` for a
loss, most recent last.

### Statistics

```bash
curl http://localhost:3000/players/stats
```

```json
{
  "bestCountry": { "code": "SRB", "winRatio": 1 },
  "averageIMC": 23.357838995505837,
  "medianHeight": 185
}
```

- `bestCountry` — wins and matches are summed per country across all its
  players; the highest `wins / matches` ratio wins.
- `averageIMC` — average body mass index (`weight / height²`) of every player.
- `medianHeight` — median height, in centimeters.

## Errors

Every failure answers with the same shape:

```json
{
  "error": "PLAYER_NOT_FOUND",
  "message": "Player with id 999 was not found"
}
```

| Status | `error` | When |
| --- | --- | --- |
| `400` | `VALIDATION_ERROR` | Invalid parameter or body |
| `404` | `PLAYER_NOT_FOUND` | No player with this identifier |
| `500` | `INTERNAL_SERVER_ERROR` | Unexpected failure |
